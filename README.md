# SmartArcs Origin - Garmin Watch Face

This watch face is designed to be a smart watch, it does not show any fitness statuses. The watch face is minimalist and highly customizable, you can easily create your very own look.

Arc indicators around the screen display:
* battery status
* number of phone notifications. First notification is displayed as five minutes arc, each other as one minute arc.
* Bluetooth status
* do not disturb status
* number of alarms. First alarm is displayed as five minutes arc, each other as one minute arc.
* sunrise, sunset and civil twilights

Text infos on the screen display:
* heart rate
* number of days to an event
* dual time ('+' means there is already next day in the dual time location, '-' means previous day)
* date

Time:
* analog hour and minute hands, with an optional second hand (never, only when awake, or always)

## Customization

Almost everything can be tailored to your taste:
* rich color palette for every element, or a single accent color applied to all indicators
* adjustable tick widths (1-minute, 5-minute and quarter-hour) and hand widths
* optional hands outline and drawing hands on top of the time infos
* toggle any indicator on or off

## On-device settings

Quick toggles are available directly on the watch (without opening the phone app) for heart rate, second hand, dual time, event countdown, power saver and lost and found.

## Power saver

The built-in power saver mode can extend battery life. You can define the schedule (begin/end time) and the screen refresh interval during that window.

## Lost and found

An optional lost and found feature can display contact details to help return the watch to its owner.
